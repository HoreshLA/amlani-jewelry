# Admin CMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give non-technical editor Hagit a Hebrew graphical admin at `/admin` to edit products, prices, images, and homepage texts, with changes committed to GitHub and auto-deployed by Netlify.

**Architecture:** Sveltia CMS (single CDN script at `site/admin/`) edits per-product JSON files in `site/content/`, homepage texts in `home.json`, and the WhatsApp number in `site.json`. A dependency-free Node `build.js` runs on Netlify: it aggregates product files into `site/products.json` and injects `home.json` texts into marked regions of `site/index.html` (keeping text in static HTML for SEO). At runtime, `collection.html`/`product.html` fetch `products.json`; `common.js` fetches `site.json`.

**Tech Stack:** Static HTML/CSS/JS (no framework, no bundler). Node (built-in `fs` only) for `build.js`. Sveltia CMS + GitHub backend + Netlify OAuth.

**Spec:** `docs/superpowers/specs/2026-10-11-admin-cms-design.md`

## Global Constraints

- No npm dependencies. `build.js` uses only Node built-ins (`fs`, `path`).
- Publish directory stays `site`. Runtime stays no-build (pages work when opened via `python -m http.server` after `products.json` exists).
- Materials are **silver 925 + gold (18k/14k) + natural gemstones**. Never "copper"/"נחושת".
- WhatsApp number default: `972502023525`.
- Hebrew is the UI/content language; pages are RTL.
- `products.json` and `site.json` are fetched with `cache: 'no-store'`.
- Keep CSS/JS `?v=N` cache-busting on `styles.css`/`common.js`; bump on code changes.

## Review Focus

- **Missing/failed `products.json` fetch** → `collection.html` and `product.html` must render their existing graceful states (categories still show, product shows "הפריט לא נמצא"), not a blank page or console crash. Pinned in Task 4.
- **`build.js` run twice (idempotency)** → second run of homepage injection must produce byte-identical `index.html`. Pinned in Task 2 self-test.
- **Product with no `gallery` / no `cover`** → `product.html` reads `p.gallery[0]`; a product saved via CMS without media must not crash the page. Pinned in Task 4.
- **`home.json` missing a key that a marker expects** → `build.js` must leave that region's existing text untouched, not blank it. Pinned in Task 2 self-test.
- **`cats` as array** → category filter uses `.indexOf()` which works on arrays; confirm empty/missing `cats` yields no match, not a throw. Pinned in Task 2 self-test (data shape) and Task 4 (filter).

### Task 2: `build.js` with self-test

**Files:**
- Create: `build.js` (repo root)

**Interfaces:**
- Produces: running `node build.js` writes `site/products.json` (array of products, each with `id` = filename) and rewrites `site/index.html` injecting `home.json` into `<!--cms:KEY-->...<!--/cms:KEY-->` regions, where `KEY` is a dot-path into `home.json` (e.g. `hero.lede`).
- Produces: `node build.js --self-test` runs assertions and exits non-zero on failure.

- [ ] **Step 1: Write the self-test and implementation together** in `build.js`:

```js
const fs = require('fs'), path = require('path');

function buildProducts(dir) {
  return fs.readdirSync(dir).filter(f => f.endsWith('.json')).sort()
    .map(f => ({ id: f.replace(/\.json$/, ''), ...JSON.parse(fs.readFileSync(path.join(dir, f), 'utf8')) }));
}

function flatten(obj, prefix = '', out = {}) {
  for (const [k, v] of Object.entries(obj)) {
    const key = prefix ? prefix + '.' + k : k;
    if (v && typeof v === 'object' && !Array.isArray(v)) flatten(v, key, out);
    else out[key] = v;
  }
  return out;
}

function injectHome(html, home) {
  const flat = flatten(home);
  return html.replace(/<!--cms:([\w.]+)-->[\s\S]*?<!--\/cms:\1-->/g, (m, key) =>
    key in flat ? `<!--cms:${key}-->${flat[key]}<!--/cms:${key}-->` : m);   // missing key -> leave region untouched
}

function main() {
  const products = buildProducts('site/content/products');
  fs.writeFileSync('site/products.json', JSON.stringify(products) + '\n');
  const home = JSON.parse(fs.readFileSync('site/content/home.json', 'utf8'));
  const html = fs.readFileSync('site/index.html', 'utf8');
  fs.writeFileSync('site/index.html', injectHome(html, home));
  console.log('built', products.length, 'products; injected home.json');
}

function selfTest() {
  // aggregation: id from filename, cats stays array, missing cats ok
  const tmp = fs.mkdtempSync('bt-');
  fs.writeFileSync(path.join(tmp, 'ring-x.json'), JSON.stringify({ name: 'X', cats: ['rings'] }));
  fs.writeFileSync(path.join(tmp, 'a-y.json'), JSON.stringify({ name: 'Y' }));
  const ps = buildProducts(tmp);
  console.assert(ps[0].id === 'a-y' && ps[1].id === 'ring-x', 'sorted + id from filename');
  console.assert(Array.isArray(ps[1].cats) && ps[0].cats === undefined, 'cats array / missing ok');
  fs.rmSync(tmp, { recursive: true });
  // injection: replaces content, idempotent, missing key untouched
  const h = { hero: { lede: 'NEW' } };
  const src = '<p><!--cms:hero.lede-->OLD<!--/cms:hero.lede--></p><i><!--cms:gone-->KEEP<!--/cms:gone--></i>';
  const once = injectHome(src, h);
  console.assert(once.includes('>NEW<') && once.includes('>KEEP<'), 'inject + missing-key untouched');
  console.assert(injectHome(once, h) === once, 'idempotent');
  console.log('self-test OK');
}

process.argv.includes('--self-test') ? selfTest() : main();
```

## Notes on testing approach

Only `build.js` has automated tests (Node `console.assert` self-test) — it holds the non-trivial logic. The browser HTML/JS changes are verified manually (Task 4 Step 5, Task 7) because the project has no JS test framework and adding one for a static site is unwarranted (YAGNI).
