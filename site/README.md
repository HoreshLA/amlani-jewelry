# Amlani · אתר תכשיטים בעבודת יד

אתר סטטי (HTML/CSS/JS) בעברית (RTL), בסגנון מינימליסטי-חם.
**רב-עמודי כמו חנות אמיתית:** עמוד בית, עמוד קולקציה, עמוד לכל מוצר, והצהרות נגישות/פרטיות.
שלב 1: קטלוג + הזמנה בוואטסאפ. בנוי כך שאפשר להוסיף בהמשך תשלום (אשראי/ביט/פייפאל).

> החומרים באתר: **כסף סטרלינג 925 וזהב (18k/14k)** ואבני חן טבעיות.
> היוצרת: **חגית עמלני**, צורפת וגמולוגית מוסמכת (IGL College).

## מבנה הקבצים
```
site/
├── index.html          ← עמוד הבית (hero, ערכים, הצצה לקולקציה, וידאו, סיפור, חומרים, הזמנה אישית, יצירת קשר)
├── collection.html     ← קולקציה: מסך קטגוריות (?cat=rings/necklaces/bracelets) → מוצרים. נבנה מ-products.json
├── product.html        ← תבנית עמוד מוצר בודד (?id=…) — נבנית מ-products.json
├── sizes.html          ← טבלת מידות טבעות + מדריך מדידה
├── accessibility.html  ← הצהרת נגישות (ת"י 5568 / WCAG 2.0 AA)
├── privacy.html        ← מדיניות פרטיות
├── content/            ← ★ מקור האמת: products/*.json (מוצר לכל קובץ), home.json, site.json (וואטסאפ)
├── products.json       ← נוצר ע"י `node build.js` (לא לערוך ידנית)
├── admin/              ← Sveltia CMS
├── common.js           ← לוגיקה משותפת (header, תפריט, אנימציות, קישורי וואטסאפ)
├── styles.css          ← כל העיצוב
└── assets/
    ├── products/       ← תמונות המוצרים
    ├── mood/           ← תמונות אווירה (hero, סיפור, רקעים)
    └── videos/         ← סרטונים (עמוד הבית + עמודי מוצר)
```

## נגישות
- **תפריט נגישות פעיל** בכל עמוד (כפתור צף עם סמל הנגישות): הגדלת/הקטנת טקסט,
  ניגודיות גבוהה, גווני אפור, הדגשת קישורים, גופן קריא, ריווח טקסט, עצירת אנימציות
  ואיפוס. ההעדפות נשמרות ב-localStorage. הקוד ב-`common.js`, העיצוב ב-`styles.css`.
- קישור "דילוג לתוכן" בראש כל עמוד (מקלדת).
- הצהרת נגישות מלאה ב-`accessibility.html` (רכז/ת נגישות: חגית).

### ⚠️ להשלים לפני עלייה לאוויר
בקובץ `accessibility.html` נותר שדה אחד: `[יש להשלים כתובת אימייל]`.
כדאי גם להוסיף אימייל ב-`privacy.html`. חפשו בקבצים את המילה "להשלים".

## איך מריצים מקומית
מתוך תיקיית `site`:
```bash
python -m http.server 8777
```
פותחים בדפדפן: http://localhost:8777

> חשוב: לא לפתוח את הקבצים בלחיצה כפולה (file://) — התמונות, ה-CSS
> וטעינת המוצרים לא יעבדו. תמיד דרך שרת (או אחסון אמיתי).

## עדכונים נפוצים

### שינוי מספר הוואטסאפ
בקובץ `content/site.json` (או ב-CMS, תחת הגדרות), בשדה `whatsapp`.
כל הכפתורים והקישורים באתר מתעדכנים אוטומטית.

### הוספת / עריכת מוצר  ← דרך ה-CMS
מוסיפים/עורכים מוצרים ב-CMS (`/admin/`). לחלופין: עורכים `content/products/*.json` ומריצים `node build.js` (מייצר את `products.json`; ב-Netlify זה רץ אוטומטית).
שדות מוצר: id, name, meta, cats (מערך: rings / necklaces / bracelets), cover, gallery, short, long, details, wa.
המוצר יופיע אוטומטית בקולקציה, בסינון, ובעמוד מוצר משלו — בלי לגעת ב-HTML.

### החלפת תמונות / סרטונים בעמוד הבית
- Hero: `assets/products/ring-moonstone-aqua.jpg` (ב-`index.html`, בתוך `.hero-media`).
- סיפור: `assets/mood/workshop-moonstone.jpg`.
- סרטוני "בתנועה": `v-b.mp4`, `v-c.mp4`, `v-f.mp4` (ב-`index.html`, בתוך `.reels`).
- רקע ההזמנה האישית: `assets/mood/rings-wine-bw.jpg` (ב-`styles.css`, `.custom`).

### צבעי המותג (ב-`styles.css`, בראש הקובץ תחת `:root`)
קרם `--cream`, אדום/חמרה `--clay`, גוון חם עדין `--gold`, טקסט `--ink`.

## שלב 2 — תשלומים (עתידי)
המבנה כבר "חנותי": לכל מוצר עמוד, כותרת, מפרט ותיאור. להוספת מכירה אונליין:
- **קל:** להוסיף שדה `price` למוצר ב-CMS ולהחליף את כפתור הוואטסאפ בעמוד המוצר
  בכפתור תשלום (PayPal / ביט / קישור סליקה).
- **חנות מלאה:** להעביר לפלטפורמה עם עגלה (Shopify / WooCommerce) תוך שמירה על אותה שפה עיצובית.
